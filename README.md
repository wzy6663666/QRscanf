# QRscanf 扫码工具

一个完全离线的 Android 二维码 / 条形码识别与生成工具，重点支持 **QR Code** 与 **Data Matrix（DM 码）**。

## 核心功能

- **单次扫码**：识别成功后立即弹出结果，显示原始内容、码制规格、内容类型与识别时间；支持复制内容。
- **连续扫码**：连续识别多个码并自动去重，点击「查看结果」一次性查看全部内容；支持复制全部、清空后重新扫描。
- **图片识别 / 批量图片识别**：从相册导入图片识别，一张图片可包含多个码；连续扫码模式下可把图片中的多个码批量加入结果。
- **码制识别**：QR Code、Data Matrix、PDF417、Aztec、Code 128、Code 39、Code 93、Codabar、EAN-13、EAN-8、ITF、UPC-A、UPC-E。
- **相机增强**：自动枚举可用镜头（后置/前置，系统暴露多摄时含超广角/长焦），支持点击切换镜头、1×–8× 变焦、双指缩放、点击对焦；分析分辨率提升，并对小码/反色/低对比码做裁剪放大、反色与对比度增强兜底。
- **扫描填充 / 复刻**：生成页内可直接拍照或从图片识别已有码，自动填入码制、内容、QR 版本/掩码/容错级别与尺寸；预览显示扫描原图的像素级复刻，可直接保存，也可按参数重新生成。
- **高级生成参数**：码制、内容、图片尺寸、QR 容错级别、QR 版本、QR 掩码、字符编码、留白模块数、前景色、背景色均可调节。
- **保存与记录**：生成的图片可保存到相册（Pictures/QRscanf）；扫码记录与生成记录保存在本地，可复制、清空。
- **设置**：识别后自动复制、扫描提示音、连续扫码自动去重。
- **完全离线**：ML Kit 条码模型打包在 APK 内，不依赖 Google Play 服务；识别与生成全部在设备本地完成，不联网、不上传数据。

## APK

- 文件：`QRscanf-v1.0.4.apk`
- 适用系统：Android 7.0（API 24）及以上
- 已使用 release 签名，可直接安装：

```bash
adb install -r QRscanf-v1.0.4.apk
```

也可以把 APK 传到手机后点击安装（需要允许「安装未知来源应用」）。

## 微信小程序版

`weapp/` 是同一套功能的微信小程序实现，用微信开发者工具导入即可运行，详见 [weapp/README.md](weapp/README.md)。

- 识别：13 种码制，由微信扫码引擎完成，本地运行不联网。
- 生成：QR Code（全参数：版本 / 掩码 / 容错 / 编码 / 尺寸 / 留白 / 配色）、Data Matrix、Code128、Code39、Code93、EAN-13、EAN-8、ITF —— 编码器均为自研纯 JS，无外部依赖。
- 扫描填充 / 复刻：选图后解析出码制、版本、掩码、纠错级别、模块尺寸、静区与配色，回填到生成页并给出对比预览。
- 暂不支持生成 PDF417 / Aztec / Codabar（可正常识别）。

## 构建

环境要求：

- JDK 17
- Android SDK Platform 37、Build-Tools 36.0.0
- Gradle 9.5（AGP 9.3.3，要求 Gradle 9.5+）

在 `local.properties` 中设置 SDK 路径，在 `gradle.properties` 中设置 `org.gradle.java.home`（指向 JDK 17），然后执行：

```bash
gradle :app:assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`。

签名配置位于 `app/build.gradle`，密钥库为 `keystore/qrscanf-release.jks`。

## 技术栈

- Java 17 / AndroidX / Material 3

## 说明

- 镜头切换列表来自手机系统实际暴露的相机。OnePlus 13 上可切换超广角（2.3mm）/ 主摄（6.1mm）/ 长焦（13.9mm）；若系统未开放某枚镜头，列表只显示可用项。关闭并重新打开应用后仍可正常切换。
- 相机端会同时运行正常与反色（高对比增强）识别通道，适合隐形油墨、深色底白码等反色 DM 码。
- 图片识别会自动尝试多个缩放尺度，并尝试反色与对比度增强，以提高小尺寸、深色底、低对比 Data Matrix 的识别率。
- 连续扫码结果按「码制 + 内容」去重，可在设置中关闭。
